Recap

How do the different file allocation methods work? Contiguous, Linked List, Indexed

  • Contiguous - this file allocation work by allocating consecutive blocks of memory to a file, making access fast but potentially causing fragmentation.
  • Linked List - this file allocation method uses pointers to link blocks together, allowing for dynamic file sizes but slower access times.
  • Indexed - this method uses an index block to keep track of all the blocks of a file, providing efficient access and flexibility.

What is the purpose of a Virtual File System (VFS)?

The purpose of a Virtual File System (VFS) is to provide a uniform interface for different file systems, allowing applications to access files without needing to know the specifics of the underlying file system.

How do the different Free-space tracking methods work? Bit Vector, Linked List, Grouping

  • Bit Vector - this method uses a bitmap to represent free and used blocks, where each bit corresponds to a block of storage.
  • Linked List - this method maintains a linked list of free blocks, allowing for easy allocation and deallocation of space.
  • Grouping - this method groups free blocks together, reducing fragmentation and improving allocation efficiency.
