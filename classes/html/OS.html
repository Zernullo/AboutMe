Summary

An Operating System (OS) is the fundamental software that enables a computer to function by managing its hardware resources and providing a platform for applications to run. It serves as a bridge between the user, application programs, and the hardware, handling tasks such as memory allocation, process scheduling, input/output operations, and file management. The OS also offers security features, networking capabilities, and a user interface—either graphical or command-line—so users can interact with the system. Examples of popular operating systems include Windows, macOS, Linux, Android, and iOS.

Computer History

Computational Hardware Timeline

1945 - Mechanical computations using gears and levers
1945-1955 - Vaccuum tubes for electronic calculations
1960 - Transistors replace vaccuum tubes
1970 - Integrated Circuits (ICs) allow for miniaturization, increased speed, and reduced cost
1980 - CPU (Central Processing Unit) becomes the brain of the computer, executing instructions and managing data flow

Enigma Machine (1930) - Used for encrypting and decrypting messages during World War II.

  • Series of rotors that changed electrical connections based on their configuration
  • Electronic Numerical Integrator and Computer
  • Made to calculate bomb trajectories
  • Used 18k vaccuum tubes
  • 5000 operations / sec (read/write/add)
  • 500 FLOPS
  • Programmed with punch cards

Univac & IBM 701 (1950s) - Early commercial computers used for business and scientific applications.

  • Universal Automatic Computer (UNIVAC)
  • First commercially available computer
  • Used for census data, weather prediction, and military applications
  • Used vaccuum tubes
  • Stored programs in memory
  • Predicted Eisenhower's landslide electoral victory in 1952
  • International Business Machines (IBM) 701 - Competitor to UNIVAC 1103, roughly same computation performance, released in 1952

Atlas (1960s) - One of the first supercomputers, used for scientific research and complex calculations.

  • Developed by the University of Manchester and Ferranti
  • Used for scientific research, weather forecasting, and nuclear simulations
  • Introduced virtual memory concept
  • Used transistors
  • Could perform 1 million instructions per second (MIPS)

PDP 7 (1960s) - Early minicomputer that made computing more accessible to smaller businesses and institutions. Unix was programmed on this

Appollo Moon Program (1960s) - Used for navigation and control of the Apollo spacecraft.

Batch Processing Systems (1950s-1960s) - Early operating systems that processed jobs in batches without user interaction.

Decsystem 10 / PDP 10 (1960s-1980s) - Time-sharing systems that allowed multiple users to access the computer simultaneously.

Multics Operating System (1964-1969) - Influential time-sharing operating system that introduced many concepts used in modern OS. Collaborative project between MIT, Bell Labs, and GE. Some modern OS concepts introduced by Multics include hierarchical file systems, dynamic linking, and security features.

PDP 11 (1970s) - Popular minicomputer that supported various operating systems, including Unix. C was developed on this. Ran very Influential OS including Unix, RT-11, and RSX-11.

UNIX (UNiplexed Information and Computing Service) (1969) - A powerful, multiuser operating system developed at Bell Labs, by Ken Thompson & Dennis Ritchie. Known for its simplicity, portability, and multitasking capabilities. Written in assembly until V4, where it was re-written in C. It introduced the concept of pipes, allowing the output of one program to be used as input for another. It also popularized the use of plain text files for configuration and data storage.

Vax (Virtual Address eXtension) (1977) - A line of computers developed by Digital Equipment Corporation (DEC) that supported the VMS operating system. Known for its virtual memory capabilities and support for multiple programming languages.

Xerox Alto (1970s) - An early personal computer developed at Xerox PARC that introduced the graphical user interface (GUI) concept. It featured a bitmapped display, a mouse, and a desktop metaphor, influencing future GUI designs.

Altair 8800 (1970s) - One of the first microcomputers, which sparked the personal computer revolution. It was based on the Intel 8080 microprocessor and was sold as a kit that users had to assemble themselves.

IBM's Personal Computer (PC) (1981) - The IBM PC set the standard for personal computers and led to the widespread adoption of the x86 architecture. It ran MS-DOS, an operating system developed by Microsoft.

Commodore 64 (1982) - A popular home computer known for its affordability and extensive software library. It featured a built-in BASIC interpreter and was widely used for gaming and educational purposes.

Macintosh (1984) - Apple's Macintosh introduced a user-friendly GUI and was one of the first computers to use a mouse. It ran the Mac OS, which emphasized ease of use and design.

Beige, Dial-up, World Wide Web (1990s) - The rise of the internet and web browsers transformed computing, making information and communication more accessible. Operating systems began to integrate networking capabilities. Birth of modern OS with Windows 95, Mac OS 8, and Linux.

Operating System Theory

An operating system (OS) is a complex piece of software that manages computer hardware and software resources, providing a stable and consistent environment for applications to run. The core functions of an OS include process management, memory management, file system management, device management, and security. Here are some key concepts in operating system theory:

1. Process Management: The OS is responsible for creating, scheduling, and terminating processes (programs in execution). It allocates CPU time to processes based on scheduling algorithms (e.g., round-robin, priority-based) and manages context switching between processes.

2. Memory Management: The OS manages the computer's memory, allocating space to processes as needed. It uses techniques like paging and segmentation to optimize memory usage and ensure that each process has access to its required memory without interfering with others.

3. File System Management: The OS provides a hierarchical file system that allows users and applications to store, retrieve, and organize data on storage devices. It handles file creation, deletion, reading, writing, and permissions.

4. Device Management: The OS manages hardware devices (e.g., printers, disk drives) through device drivers that facilitate communication between the OS and the hardware. It handles input/output operations and ensures efficient use of devices.

5. Security and Protection: The OS implements security measures to protect data and resources from unauthorized access. This includes user authentication, access control lists (ACLs), encryption, and secure communication protocols.

6. User Interface: The OS provides a user interface (UI), which can be command-line based or graphical (GUI), allowing users to interact with the system and manage files, applications, and settings.

7. Multitasking and Multiprocessing: Modern operating systems support multitasking (running multiple processes simultaneously) and multiprocessing (using multiple CPU cores) to improve performance and responsiveness.

8. Virtualization: Many operating systems support virtualization technologies that allow multiple virtual machines (VMs) to run on a single physical machine, enabling better resource utilization and isolation.


Sturcture of an OS:
1. Kernel: The core component of the OS that manages system resources and provides essential services to other parts of the OS and applications. It operates in a privileged mode (kernel mode) with direct access to hardware.

2. Application Layer: The layer where user applications run. It interacts with the OS through system calls to request services like file access, memory allocation, and process management.

3. Device Drivers: Software modules that allow the OS to communicate with hardware devices. They translate OS commands into device-specific operations.

4. TCP/IP Stack: A set of protocols that enable network communication. The OS manages the TCP/IP stack to facilitate data transmission over networks.

5. File System: The component that organizes and manages data storage on disks and other storage devices. It provides a way to create, read, write, and delete files.

MS-DOS (Microsoft Disk Operating System) - An early operating system for IBM PCs and compatibles, known for its command-line interface and simplicity. It was widely used in the 1980s and early 1990s before being largely replaced by Windows.

Monolithic Kernel - A kernel architecture where all OS services run in a single address space, providing high performance but potentially less stability due to the lack of isolation between services. Examples include Linux and traditional Unix systems. User Space interacts with kernal through system calls (Example: read(), write(), open(), close()). Windows and Linux are examples of monolithic kernels.
1. Kernal Space - The privileged mode where the kernel operates, with direct access to hardware and system resources. Splits User space and kernal space.
2. User Space - The non-privileged mode where user applications run, with restricted access to system resources.

Hybrid Kernel - A kernel architecture that combines elements of monolithic and microkernel designs, aiming to balance performance and modularity. Examples include Windows NT, MacOS IOS, and Andriod. It runs some services in kernal space and some in user space.
